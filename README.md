# Young Midfielder Recruitment Analysis

A statistical screening project for midfielders aged 23 or younger in Europe's Big Five leagues.

The project uses per-90 metrics, correlation analysis, percentiles, and six statistical dimensions to compare player profiles and create recruitment shortlists.

## Main steps

- Filter eligible U23 midfielders
- Convert count statistics to per-90 values
- Examine correlations between metrics
- Select less redundant metrics
- Convert metrics into percentiles
- Build six performance dimensions
- Apply recruitment criteria to generate a shortlist

## Tools

- Python
- pandas
- matplotlib
- Jupyter Notebook

## Data

The dataset was obtained from Kaggle and is based on 2024/25 player statistics from Europe's Big Five leagues.
